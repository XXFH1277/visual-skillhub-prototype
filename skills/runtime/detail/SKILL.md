# 详情页分镜

每屏是一张 3:4 竖版的完整设计稿（画面 + 排版文字），整套像同一天、同一个摄影师和设计师做出来的。

## 叙事顺序（按屏数取舍）
1. 首屏主视觉：商品 + 道具组成的大片，品牌名/概念一句话。
2. 核心卖点：最强差异点，一屏只讲一件事。
3. 材质与细节：近距离特写，可做 2–3 格小图拼排。
4. 使用场景：人或手与商品的互动，或生活场景。
5. 更多卖点 / 成分 / 工艺：可用图文分栏、小图标排版。
6. 收尾：品牌态度、使用建议或规格（规格只用商家给的数据）。

## 每屏写什么
- scene：画面（商品位置与大小、道具、背景、光）+ 排版（标题在哪、竖排还是横排、正文几行在哪、是否有分栏小图）。
- texts：headline 4–12 字；body 1–2 行、每行不超过 20 字；可加 tag 英文小标。
- 全套统一：色板、光线方向、字体系统、留白节奏一致；相邻屏靠景别和构图区分（全景→特写→场景）。
- 只用商家给的事实；没写的参数、认证、销量、功效一律不写。
