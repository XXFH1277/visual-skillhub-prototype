# 商品图工作流

执行网站提供的逐张计划。先观察第一张附件的轮廓、颜色、比例、接缝、标签和已展示部件，再依据场景和事实组织画面。
后续附件仅提供风格，不替换商品。未知材质按外观表现，不推断物性；不旋转到未展示的背面，不补造配件、拆解或性能效果。
主图保持完整轮廓与清晰背景；细节图只放大可见局部并留辨识背景；场景图保持可信尺度和正确使用方式，不把装饰道具表示为随附商品。
按逐张计划中的统一配色、光线、材质和镜头方向生成。多张图改变画面目的而非商品身份。
textMode=none 时只保留实物原有标签，不新增营销文字。supplied 时只将 copy 中原文排入画面，不从事实、受众或说明中自行补文案。
检查轮廓、Logo、标签、数量、文案和场景尺度；无证据的卖点不能通过夸张效果图展示。

## 参考与运行适配

运行器同时加载归档 `gpt-image2-ecommerce/SKILL.md` 的“转化驱动力诊断”，以及其 `references/craft.md` 的“光照三要素”“编辑 prompt 的黄金结构”两个章节。驱动力决定画面表达，不改变已确认的逐张用途或事实。
本适配由网站完成输入校验、逐张计划、风格锁定、调用和交付；不运行原项目脚本或模型路由，不生成额外角度图，不自动增加收费调用。
