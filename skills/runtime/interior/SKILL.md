# 空间改造工作流

第一张附件是现状空间照片，不是商品。先观察房间边界、墙面、地面、天花、梁柱、门窗、固定设施及透视消失点。后续附件只提供风格、材质与配色，不把参考房间的户型移入现状。
所有方案固定原图镜头位置、视线高度、主要透视和空间尺度。保留墙体边界、梁柱、门窗的位置与数量、出入口和固定设备位置，不拆墙、增窗、移动水电或虚构相邻房间。
scope=soft：仅在允许改动清单内替换活动家具、灯具外观、窗帘、地毯、装饰；保留原墙地顶饰面、橱柜和其他固定设施。对灯具只改变外观，不新增线路与灯位。
scope=finishes：可在允许改动清单内调整墙地顶饰面与软装，但保留建筑结构、固定设施位置、门窗尺寸关系。不根据风格参考自行扩宽房间或改变布局。
用户额外保留清单优先于允许改动；改造范围优先于风格和材质偏好。出现冲突时保留受保护对象，仅在其余允许范围展示风格，不擅自扩大改造范围。
保持家具尺寸关系、通道与开门空间可信，避免悬浮家具、重复窗户、异常透视、遮挡通道。日光来自已有窗户，夜景来自已有灯位；反射、阴影与材质粗糙度一致。
输出同一空间、同一视角的独立方案，不做拼图或未经证实的前后对比；不加价格、营销标题、Logo、尺寸线或装修预算。
效果图用于风格与视觉探索，不表示实测尺寸、施工图、结构鉴定或工程可行性。交付核对重点是门窗/梁柱位置、透视、保留对象、改动范围和通道。

## 运行适配

此 Skill 为 SkillHub 原创空间流程，独立于电商 Skill。网站校验房间类型、范围、改动清单、材质和光照后，建立逐张方案；Codex 与图片 API 加载完全相同的空间规则。没有调用商品营销规则或第三方装修软件。
