# 海报工作流

先建立阅读顺序：主标题、补充信息、正文或菜单、优惠、行动文案、落款。按用户选定的版式安排文字安全区与主视觉，不让文字遮挡脸、商品标识或重要信息。
逐字使用 poster 的已填写文案，保留换行意义与菜单名称价格对应关系。空字段省略，不自行补折扣、活动日期、联系信息、二维码或背书。
top：上方标题区，下方主视觉与补充信息；side：左右图文分区；typography：文字作为主要视觉；auto：根据文案长度建立清晰层级。
促销突出已确认优惠；活动突出主题与已给时间地点；品牌突出主题与落款；菜单突出条目对齐、价格对应和足够行距。
有主素材时保留主体身份；仅参考图时借鉴风格而不复制其文字或品牌；无附件时使用原创文字和图形布局。
多方案保持相同文案与配色，允许变化版式节奏。交付前检查遗漏、重复、错字、数字和安全边距；程序并没有 OCR 验证，成图仍需人工核对。

## 参考与运行适配

运行器加载归档 `gpt-image2-ecommerce/references/craft.md` 的“视线引导”“留白与占比”章节作为版式参考；占比是建议，不覆盖文字可读性和用户指定版式。
这是 SkillHub 的专用海报 Skill，未安装迅排编辑器；生成调用由网站选定的 Codex 或图片 API 执行。
