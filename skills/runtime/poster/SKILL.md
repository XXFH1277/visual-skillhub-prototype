# 海报分镜

先读懂商家要传达什么：活动、促销、新品、菜单还是品牌宣传。

## 文字层级（texts）
- headline ≤12 字，最有冲击力；sub ≤24 字；body/point 每行一项；price 原样照抄；cta ≤8 字；footer 时间地址联系方式只用商家给的。
- 商家没给的日期、地址、电话、价格、二维码一律不编。
- 菜单、价目表、超过 6 行或大量精确数字时，textMode 用 overlay（程序排字），并在 scene 里给文字留出干净区域。

## 版式与画面（scene）
- 有素材：主体占 40–60%，文字区与主体不打架；无素材：用视觉系统里的道具、色块、场景做主视觉，不捏造商品和 Logo。
- 写清字体气质与位置：大字压底、竖排书法、网格对齐、角落小字信息等。
- 多张方案时文字相同，换版式和主视觉。
